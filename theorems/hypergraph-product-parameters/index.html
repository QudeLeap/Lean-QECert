Coding theory / Theorem

General hypergraph-product code parameters

Theorem statement

For $i\in\{1,2\}$, let $\mathcal G_i$ be a Tanner graph with variable-node set $V_i$ and check-node set $W_i$, defining a binary linear code $\mathcal C_i$. Write $n_i=|V_i|$ and $r_i=|W_i|$, let $k_i$ and $k_i^T$ be the dimensions of $\mathcal C_i$ and its transpose code, and let $d_i$ and $d_i^T$ be their minimum distances, with the source convention that the distance of the zero code is infinity. The Tillich--Zemor hypergraph-product construction defines a CSS quantum code with $N=n_1 n_2+r_1 r_2$, $K=k_1 k_2+k_1^T k_2^T$, and $D\geq\min(d_1,d_2,d_1^T,d_2^T)$. Equality holds if some $d_i$ realizes the displayed minimum and $d_{3-i}$ is finite, or if some $d_i^T$ realizes it and $d_{3-i}^T$ is finite. The Tillich--Zemor hypergraph-product degree formulas show that uniformly bounded input degrees give uniformly bounded output check and qubit degrees. In the diagonal full-rank specialization of the Tillich--Zemor hypergraph-product construction obtained by using the same full-rank parity-check matrix $H$ twice for a binary $[n,k,d]$ LDPC code, $N=n^2+(n-k)^2$, $K=k^2$, and $D=d$; every stabilizer row weight is the corresponding input row weight plus the corresponding input column weight.
$G$
Base symbol parsed from \mathcal G_i; the indexed Tanner graph is registered as G_i.
