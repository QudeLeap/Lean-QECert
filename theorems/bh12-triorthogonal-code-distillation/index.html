Magic-state distillation / Theorem

BH12 triorthogonal-code distillation family

Theorem statement

For every positive even $k$, there is an explicit triorthogonal/CSS family with $n=3k+8$ physical qubits and $k$ logical qubits whose minimum weight of a nontrivial pure-Z logical operator is $d_Z=2$. The corrected physical transversal $T$ implements a simultaneous logical $T$ layer. For sufficiently small input error $p$, independent diagonal noisy resources feed the actual syndrome-postselected protocol, which has positive acceptance probability and each actual output marginal is $O(p^2)$. Fresh-parent recursion with pooling gives successful-output cost $O(\log(1/\epsilon)^{\gamma_k})$ at target error $\epsilon$, where $\gamma_k=\log((3k+8)/k)/\log 2$. Along positive even $k$, the exponent approaches $\log 3/\log 2$, and no fixed finite block attains that limit.
