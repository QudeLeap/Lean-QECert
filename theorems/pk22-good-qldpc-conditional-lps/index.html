Quantum LDPC / Theorem

PK22 good qLDPC codes assuming the LPS spectral theorem

Theorem statement

Assume, as an external premise, the published LPS spectral theorem on the actual selected non-bipartite LPS Cayley graph family: its unnormalized complex adjacency operator restricted to zero-sum functions has norm at most twice the square root of one less than the graph degree. For every real $R$ with $0<R<1$ and every finite field $\mathbb{F}_q$, there is an explicit family of quantum LDPC codes over that field with unbounded physical block length. One family-independent bound controls both stabilizer-check weight and the number of checks incident to each physical qudit. For all sufficiently large block lengths $n$, the encoded dimension $k$ and distance $d$ satisfy $k\ge Rn$ and positive family-independent lower and upper bounds on $d/n$. One fixed finite Boolean program outputs all scalar-decorated sparse CSS checks of this same family in time bounded by a fixed polynomial in the physical output code length; decoding those outputs defines exactly the code carrier. The LPS spectral premise is retained explicitly and is not proved by this conditional coding theorem.
