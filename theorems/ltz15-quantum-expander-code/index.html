LTZ15 quantum-expander construction and distance

Theorem statement

Let $G=(A\cup B,E)$ be a biregular bipartite graph whose vertex parts $A$ and $B$ are nonempty, with $|A|=n_A$, $|B|=n_B$, strictly positive left degree $\Delta_A$, strictly positive right degree $\Delta_B$, and $n_B\leq n_A$, hence $\Delta_A\leq\Delta_B$. Let $H$ be its binary $n_B\times n_A$ incidence matrix, constructed from $G$, and let $C_G$ be the binary classical code with parity-check matrix $H$. The Leverrier--Tillich--Zemor diagonal hypergraph-product construction sets $H_X=(I_{n_A}\otimes H,H^T\otimes I_{n_B})$ and $H_Z=(H\otimes I_{n_A},I_{n_B}\otimes H^T)$. The rows of $H_X$ are orthogonal to the rows of $H_Z$, so they define the CSS code $Q_G$; each check row has weight $\Delta_A+\Delta_B$. This code has $N=n_A^2+n_B^2$, $K\geq(n_A-n_B)^2$, and $D=\min(d,d^T)$, where $d$ is the least cardinality of a nonempty set of columns of $H$ summing to zero over $\mathbb{F}_2$, and $d^T$ is defined analogously using a nonempty set of rows; either value is infinity when no such set exists. The graph is left-right expanding for $\gamma_A,\delta_A,\gamma_B,\delta_B>0$ when every $S\subseteq A$ with $|S|\leq\gamma_A n_A$ satisfies $|\Gamma(S)|\geq(1-\delta_A)\Delta_A|S|$, and every $S\subseteq B$ with $|S|\leq\gamma_B n_B$ satisfies $|\Gamma(S)|\geq(1-\delta_B)\Delta_B|S|$. If $\delta_A<1/2$ and $\delta_B<1/2$, then $D\geq\min(\gamma_A n_A,\gamma_B n_B)$.
