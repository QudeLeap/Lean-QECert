  1. QEC semanticsTheorem
    Knill-Laflamme criterion for a finite Kraus channel

    Let $C$ be a quantum code and $(K_i)_{i\in I}$ a complete finite Kraus family on the same finite-dimensional Hilbert space, so $\sum_{i\in I} K_i^\dagger K_i=I$. Then the following are equivalent: (1) there are scalars $\alpha_{ij}$ such that $\langle K_i\psi,K_j\phi\rangle=\alpha_{ij}\langle\psi,\phi\rangle$ for all $i,j\in I$ and all $\psi,\phi\in C$; and (2) there exists a CPTP recovery channel $R$ such that $R(\sum_{i\in I}K_i\rho K_i^\dagger)=\rho$ for every density operator $\rho$ supported on $C$.

  2. Locality tradeoffsBound
    Dai--Li optimal locality tradeoff

    There exist absolute real constants $c_0,c_1>0$ such that, for every finite binary $[[n,k,d]]$ stabilizer code equipped with one fixed independent Pauli-generator family $G$ and every unit-separated embedding into $\mathbb{R}^2$, if $c_1 n\le k d^2$, then at least $c_0\max(k,d)$ distinct unordered pairs $\{p,q\}$ with $p\ne q$ that occur together in the support of some generator in $G$ have Euclidean length at least $c_0\max\left(d/\sqrt n,\sqrt[4]{k d^2/n}\right)$. Each pair is counted once even if several members of $G$ support it. Both roots are the principal nonnegative real roots. This fixes $G$ and makes no generator-family invariance claim. Lean-QEC proves this exact finite binary specialization with witnesses $c_0=1/200$ and $c_1=1000^4$; these witness constants arise from the Lean-QEC proof, including its project-owned repair of DL24 Lemma square-3, and are not attributed to DL24.

  3. Coding theoryTheorem
    Chain-complex CSS homological distance

    Let $\mathbb{F}_2^\lambda \xrightarrow{\partial_2} \mathbb{F}_2^\iota \xrightarrow{\partial_1} \mathbb{F}_2^\kappa$ be a finite based binary chain complex, so $\partial_1\partial_2=0$, and form its associated CSS code. Its pure-X logical quotient is $\ker(\partial_2^\top)/\operatorname{im}(\partial_1^\top)=H^1$, while its pure-Z logical quotient is $\ker(\partial_1)/\operatorname{im}(\partial_2)=H_1$. The algebraic CSS distance $d$ is the least Hamming weight of a representative whose class is nontrivial in either quotient. Whenever exact sector minima $d_X$ and $d_Z$ exist, $d=\min(d_X,d_Z)$.

  4. Coding theoryTheorem
    Stabilizer detectable-error characterization

    Let $S$ be a source-valid stabilizer group with $-I\notin S$, and let $T$ be exactly its common-fixed code: its vectors are precisely those fixed by every element of $S$. Work in the selected binary Pauli representative model. For binary representatives $E$ and $P$, write $E\sim_{\pm}P$ when they have the same binary Pauli vector, equivalently when they differ by one of the two stored signs, and let $N(S)$ be the code-level binary normalizer. Then the full scalar matrix-element characterization is $(\exists c\in\mathbb{C}\;\forall \psi,\phi\in T,\;\langle\psi,E\phi\rangle=c\langle\psi,\phi\rangle)\Longleftrightarrow((\exists P\in S,\;E\sim_{\pm}P)\lor E\notin N(S))$. In the generated-stabilizer-up-to-sign branch, the error acts by the selected sign scalar. Outside the normalizer, it anticommutes with a stabilizer element and all code matrix elements vanish. Conversely, an error in $N(S)$ with no $P\in S$ satisfying $E\sim_{\pm}P$ induces a nontrivial logical action on $T$ and is undetectable. Gottesman's Pauli group includes four global phases; the displayed equivalence intentionally selects the two-valued binary representative convention and does not assert membership up to an arbitrary complex multiple, while the matrix-element scalar $c$ remains complex.

  5. Coding theoryTheorem
    Binary CSS checks commute iff dual containment

    Let $R_X$ and $R_Z$ be binary linear row codes on the same finite coordinate set, used respectively for the X- and Z-type checks in the combined CSS check set. The combined set is pairwise commuting if and only if the binary word pairing (equivalently, binary dot product) satisfies $\langle x,z\rangle_2=0$ for every $x\in R_X$ and $z\in R_Z$; this is equivalent to $R_Z\subseteq R_X^\perp$ and, symmetrically, to $R_X\subseteq R_Z^\perp$. In the parity-check notation of [Gott97], $R_Z=\operatorname{row}(P)=C_P^\perp$ supplies the Z-type checks, while $R_X=\operatorname{row}(Q)=C_Q^\perp$ supplies the X-type checks.

  6. QEC semanticsTheorem
    Finite Pauli-Kraus channel correctability criterion

    Let $S$ be a source-valid binary stabilizer group and $T$ its exact common-fixed code. Let $(E_i)_{i\in I}$ be a finite family of binary Pauli representatives, and let $K_i=a_iE_i$ form a complete finite Kraus channel. Write $I_+=\{i\in I\mid a_i\ne 0\}$. Then there exists a CPTP recovery channel $R$ such that $R(\sum_{i\in I}K_i\rho K_i^\dagger)=\rho$ for every density operator $\rho$ supported on $T$ if and only if, for every $i,j\in I_+$, the relative Pauli $E_i^\dagger E_j$ belongs to the generated stabilizer up to the selected binary sign or lies outside the binary normalizer $N(S)$.

  7. Coding theoryTheorem
    Stabilizer distance-normalizer characterization

    Let $S$ be a source-valid binary stabilizer group and $T$ its exact common-fixed code. A natural number $d$ is a finite semantic Pauli distance when some binary Pauli $E$ of weight $d$ fails the scalar matrix-element condition on $T$, while every Pauli failing that condition has weight at least $d$. Then $d$ is a finite semantic Pauli distance if and only if there is an $E\in N(S)$ of weight $d$ for which no $P\in S$ satisfies $E\sim_{\pm}P$, and every $A\in N(S)$ with no such stabilizer representative has weight at least $d$. If this normalizer logical sector is empty, no finite $d$ exists under this convention.

  8. Coding theoryTheorem
    CSS stabilizer code from parity checks

    Let $R_Z=\operatorname{im}P^\top$ and $R_X=\operatorname{im}Q^\top$. If every row of $P$ is orthogonal to every row of $Q$, map the $P$-rows to Z checks and the $Q$-rows to X checks and let $S$ be their generated binary Pauli stabilizer. Then $S$ is abelian, $-I\notin S$, the finite row family generates $S$, and the resulting code is exactly $T=\{\psi:\forall M\in S,\;M\psi=\psi\}$.

  9. Coding theoryTheorem
    Stabilizer degeneracy below distance characterization

    Let $S$ be a source-valid binary stabilizer group, let $T$ be its exact common-fixed code, and let $d_S$ be a finite semantic Pauli distance of $T$. Call the code semantically degenerate at $d_S$ when there exist a binary Pauli $E$ and a nonzero scalar $c\in\mathbb{C}$ such that $E$ is not equivalent to the identity up to binary sign, $\operatorname{wt}(E)<d_S$, and $\langle\psi,E\phi\rangle=c\langle\psi,\phi\rangle$ for all $\psi,\phi\in T$. Then the code is semantically degenerate at $d_S$ if and only if there exist $E$ and $P\in S$ such that $E\sim_{\pm}P$, $E$ is not equivalent to the identity up to binary sign, and $\operatorname{wt}(E)<d_S$. Equivalently, under the same finite-distance hypothesis, the code is nondegenerate exactly when every generated-stabilizer representative not equivalent to the identity up to binary sign has weight at least $d_S$. This statement applies only when a finite semantic distance exists. It does not encode the separate [n,0,d] convention or identify k=0 with an empty logical sector.

  10. Coding theoryTheorem
    Stabilizer syndrome map laws

    Let $J$ be a finite set, let $M$ be a $J$-indexed family of binary Pauli generators for a stabilizer $S$, and define the generator-indexed syndrome $f_M(E)\in\mathbb{F}_2^J$ by declaring $f_M(E)(j)=0$ exactly when $E$ commutes with the generator at $j\in J$, and $f_M(E)(j)=1$ exactly when it anticommutes. For all binary Pauli errors $E,A,B$, the laws are $f_M(E)=0\Longleftrightarrow E\in N(S)$ and $f_M(A)=f_M(B)\Longleftrightarrow f_M(AB)=0$. Moreover, the source product $AB$ and the relative product $A^\dagger B$ differ only by a binary global phase, so $f_M(AB)=f_M(A^\dagger B)$. Thus the second equivalence is unchanged when written with the relative product.

  11. Quantum LDPCTheorem
    Uniform chain-complex CSS row checks witness stabilizer-family LDPC

    Let $(K_a)_a$ be a family of finite based binary three-term chain complexes, and let $Q_a$ be the induced CSS stabilizer code with stabilizer group $S_a$. Suppose there is one $w\in\mathbb{N}$ such that every basis-row X- or Z-type check has Pauli weight at most $w$, and every qubit $q$ belongs to the support of at most $w$ distinct basis-row checks. Then $(Q_a)_a$ is an LDPC stabilizer-code family: there exists the same family-independent $w$ such that, for every $a$, the finite row-check set $G_a$ generates $S_a$, every member of $G_a$ has weight at most $w$, and every qubit belongs to the support of at most $w$ members of $G_a$.

  12. Coding theoryTheorem
    Bounded nondegenerate correctable-error syndrome injectivity

    Let $S$ be a source-valid binary stabilizer group, let $T$ be its exact common-fixed code, and let $M$ be a finite $J$-indexed binary Pauli generator family whose generated stabilizer is exactly $S$. Suppose $T$ has finite semantic Pauli distance $d$ and is nondegenerate at $d$. Let $K_i=a_iE_i$, $i\in I$, be a complete finite binary-Pauli Kraus family for which there exists a CPTP recovery channel correcting $T$, and let $I_+=\{i\in I\mid a_i\ne 0\}$ be its active support. Assume $\operatorname{wt}(E_i)\le t$ for every $i\in I_+$ and $2t<d$. Then, for all $i,j\in I_+$, $f_M(E_i)=f_M(E_j)\Longrightarrow E_i\sim_{\pm}E_j$. Thus the generator-indexed syndrome is injective on the active physical binary-Pauli errors modulo stored global sign. If the chosen active representatives have no duplicates modulo stored sign, then $i\mapsto f_M(E_i)$ is injective on $I_+$.

  13. Coding theoryTheorem
    CSS quantum/classical syndrome equality

    Let $P:\mathbb{F}_2^\iota\to\mathbb{F}_2^{\kappa_P}$ and $Q:\mathbb{F}_2^\iota\to\mathbb{F}_2^{\kappa_Q}$ be binary parity-check maps whose rows are mutually orthogonal. Index the CSS generators by the tagged union of $\kappa_P$ and $\kappa_Q$, with $M_{\operatorname{inl}(p)}=Z(P^\top e_p)$ and $M_{\operatorname{inr}(q)}=X(Q^\top e_q)$. For a binary Pauli $E=(x_E,z_E)$, define $f_{P,Q}(E)_j=\langle(x_E,z_E),M_j\rangle_{\mathrm{sp}}$. Then $f_{P,Q}(E)_{\operatorname{inl}(p)}=(P x_E)_p$ and $f_{P,Q}(E)_{\operatorname{inr}(q)}=(Q z_E)_q$. Equivalently, under the canonical splitting, $f_{P,Q}(E)=\operatorname{Sum.elim}(P x_E)(Q z_E)$. In the Q branch the symplectic calculation gives $-(Q z_E)_q=(Q z_E)_q$ because the field has characteristic two. Pure X and Z errors give $(P x,0)$ and $(0,Q z)$. A Y-support word $y$, represented by $x_E=z_E=y$, gives $(P y,Q y)$. Its two components are nonzero exactly when $P y$ and $Q y$ are nonzero, respectively; neither follows merely from $y$ being nonzero.

  14. Coding theoryTheorem
    Componentwise CSS finite-family Knill-Laflamme

    Let $P:\mathbb{F}_2^\iota\to\mathbb{F}_2^{\kappa_P}$ and $Q:\mathbb{F}_2^\iota\to\mathbb{F}_2^{\kappa_Q}$ be binary parity-check maps with mutually orthogonal rows. Let $T_{P,Q}$ be their actual common $+1$ fixed CSS carrier: P-row Z checks detect the X component $x$, and Q-row X checks detect the Z component $z$. Let $t_X,t_Z\in\mathbb{N}$, and suppose P is injective on the Hamming ball of radius $t_X$ and Q is injective on the Hamming ball of radius $t_Z$. Let $I$ be finite, let $E_i=(x_i,z_i)$ be binary Pauli representatives, let $K_i$ be $a_i$ times the Pauli operator represented by $E_i$, and write $I_+=\{i\in I\mid a_i\ne 0\}$. If $\operatorname{wt}(x_i)\le t_X$ and $\operatorname{wt}(z_i)\le t_Z$ for every $i\in I_+$, then there are scalars $c_{ij}$ such that $\langle\psi,K_i^\dagger K_j\phi\rangle=c_{ij}\langle\psi,\phi\rangle$ for all $i,j\in I$ and $\psi,\phi\in T_{P,Q}$. Thus the finite family satisfies the same-space Knill-Laflamme matrix-element condition on $T_{P,Q}$. A Y coordinate contributes to both component bounds. No completeness or normalization condition is assumed.

  15. QEC semanticsTheorem
    CSS componentwise X/Z/Y correction from classical codes

    Let $P:\mathbb{F}_2^\iota\to\mathbb{F}_2^{\kappa_P}$ and $Q:\mathbb{F}_2^\iota\to\mathbb{F}_2^{\kappa_Q}$ be binary parity-check maps with mutually orthogonal rows, and let $T_{P,Q}$ be the exact common-fixed CSS code generated by the P-row Z checks and Q-row X checks. Let $t_X,t_Z\in\mathbb{N}$. Assume P is injective on the Hamming ball of radius $t_X$ and Q is injective on the Hamming ball of radius $t_Z$. Let I be finite, let $E_i=(x_i,z_i)$ be binary Pauli representatives, let $K_i=a_iE_i$, and write $I_+$ for the set of indices $i$ for which $a_i$ is nonzero. Suppose every $i\in I_+$ satisfies $\operatorname{wt}(x_i)\le t_X$ and $\operatorname{wt}(z_i)\le t_Z$, and the finite Kraus family is complete, $\sum_i K_i^\dagger K_i=I$. Then there exists a CPTP recovery channel correcting $T_{P,Q}$ for this Kraus family. Moreover, if $y$ is nonzero, $\operatorname{wt}(y)\le t_X$, and $\operatorname{wt}(y)\le t_Z$, bounded-ball injectivity gives nonzero words $P y$ and $Q y$; the equal-X/Z Y-support syndrome is $(P y,Q y)$, so both syndrome components are nonzero. Thus a Y coordinate contributes once to each separate component bound. This conclusion uses neither a total-Pauli-weight radius nor a CSS distance formula.

  16. Coding theoryTheorem
    CSS stabilizer distance is the minimum logical-sector distance

    Let $R_Z=\operatorname{im}P^\top$, $R_X=\operatorname{im}Q^\top$, $C_P=\ker P$, and $C_Q=\ker Q$, and form the source-valid CSS stabilizer code from $P,Q$. Assume the X- and Z-logical sectors are nonempty, and let $d_X=\min\{\operatorname{wt}(x):x\in C_P,\ x\notin R_X\}$ and $d_Z=\min\{\operatorname{wt}(z):z\in C_Q,\ z\notin R_Z\}$. Its finite semantic Pauli distance is $d_S=\min(d_X,d_Z)$. The semantic distance is the independently defined scalar-matrix-element detectability predicate; it is not defined by this equality. If either logical sector is empty, that sector has no finite natural-valued minimum under the semantic convention rather than an arbitrarily assigned finite value.

  17. Coding theoryTheorem
    CSS distance is the minimum ordinary classical distance under strict purity

    Let $R_Z=\operatorname{im}P^\top$, $R_X=\operatorname{im}Q^\top$, $C_P=\ker P$, and $C_Q=\ker Q$, and form the source-valid CSS stabilizer code with stabilizer group $S$. Let $d_P$ and $d_Q$ be the ordinary nonzero minimum distances of $C_P$ and $C_Q$. Assume strict generated-group purity at the ordinary threshold: every binary Pauli $E$ satisfying $E\sim_{\pm}S$ and not equivalent up to sign to the identity $I$ also satisfies $\min(d_P,d_Q)<\operatorname{wt}(E)$. Then the finite semantic Pauli distance of the CSS stabilizer code is $d_S=\min(d_P,d_Q)$. This purity condition is structural and stronger than the conclusion: it prevents a minimum-weight classical word from being only a degenerate stabilizer and does not restate the logical-distance equality.

  18. Quantum LDPCTheorem
    Conditional LZ22 asymptotically good Quantum Tanner codes

    Fix real parameters $\rho,\epsilon,\delta$ with $0<\rho<1/2$, $0<\epsilon<1/2$, $0<\delta<1/2$, and $-\delta\log_2\delta-(1-\delta)\log_2(1-\delta)<\rho$. Let $\Delta$ be a sufficiently large fixed degree in the selected odd-prime-degree arithmetic PSL2 subsequence of LZ22. Assume, as an external spectral premise, that on each actual left and right Cayley graph of this family the complex adjacency operator restricted to zero-sum functions has operator norm at most $2\sqrt{\Delta}$. Put $r=\lfloor\rho\Delta\rfloor$. Choose the binary local code $C_A\subseteq\mathbb{F}_2^\Delta$ as the row span of a uniformly random $r\times\Delta$ generator matrix and $C_B\subseteq\mathbb{F}_2^\Delta$ as the kernel of a uniformly random $r\times\Delta$ parity-check matrix. With nonzero probability, fixing this one pair of local codes on the selected infinite family $X$ of TNC left-right Cayley square complexes yields a family $Q$ with arbitrarily large block lengths of binary Quantum Tanner CSS codes. Every member has block length $n$, encoded dimension $k$, and minimum distance $d$ satisfying $k\ge(1-2\rho)^2n$ and $d\ge\delta n/(4\Delta^{3/2+\epsilon})$. Every selected stabilizer generator has weight at most $\Delta^2$, and every qubit belongs to at most $\Delta^2$ selected generators, so this is a quantum LDPC family because $\Delta$ is fixed before the family grows. The probability is only over the local-code matrices chosen before the infinite family; no deterministic or explicit successful choice is asserted.

  19. Coding theoryTheorem
    General hypergraph-product code parameters

    For $i\in\{1,2\}$, let $\mathcal G_i$ be a Tanner graph with variable-node set $V_i$ and check-node set $W_i$, defining a binary linear code $\mathcal C_i$. Write $n_i=|V_i|$ and $r_i=|W_i|$, let $k_i$ and $k_i^T$ be the dimensions of $\mathcal C_i$ and its transpose code, and let $d_i$ and $d_i^T$ be their minimum distances, with the source convention that the distance of the zero code is infinity. The Tillich--Zemor hypergraph-product construction defines a CSS quantum code with $N=n_1 n_2+r_1 r_2$, $K=k_1 k_2+k_1^T k_2^T$, and $D\geq\min(d_1,d_2,d_1^T,d_2^T)$. Equality holds if some $d_i$ realizes the displayed minimum and $d_{3-i}$ is finite, or if some $d_i^T$ realizes it and $d_{3-i}^T$ is finite. The Tillich--Zemor hypergraph-product degree formulas show that uniformly bounded input degrees give uniformly bounded output check and qubit degrees. In the diagonal full-rank specialization of the Tillich--Zemor hypergraph-product construction obtained by using the same full-rank parity-check matrix $H$ twice for a binary $[n,k,d]$ LDPC code, $N=n^2+(n-k)^2$, $K=k^2$, and $D=d$; every stabilizer row weight is the corresponding input row weight plus the corresponding input column weight.

  20. Quantum LDPCTheorem
    HHO20 fiber-bundle and qLDPC families

    Over $\mathbb{F}_2$, the Hastings--Haah--O'Donnell randomized fiber-bundle construction uses a one-dimensional classical-code base $\mathcal B$, a cycle-graph fiber, and a connection assigning rotation twists to incident base cells. Each rotation commutes with the fiber boundary, so the associated twisted boundary squares to zero. Writing $n_B,m_B$ for the numbers of variable $1$-cells and check $0$-cells of the base and $n_F,m_F$ for the numbers of fiber $1$- and $0$-cells, it takes $m_B=\frac{3}{4}n_B$ and $n_F=m_F=\ell^2$. The base average degree is proportional, above and below, to $(\log n_B)^2$, the number of twist types is proportional, above and below, to $\log n_B$, and every twist is a multiple of $\ell$. The base Tanner graph, its head--tail partitions, and the twist values are randomly selected. With high probability these selected data have the required rank, distance, degree, and twist-expansion properties; they are construction outputs, not caller-supplied assumptions. The resulting twisted complex defines a binary CSS code on $N=n_B m_F+m_B n_F$ qubits. Choosing $n_B$ proportional to $m_F$ gives encoded dimension $K$ bounded above and below by positive constant multiples of $N^{1/2}$, $d_X=\Omega(N^{1/2}/(\log N)^2)$, and $d_Z=\Omega(N^{3/4}/(\log N)^2)$, while stabilizer-generator weights and qubit participation are polylogarithmic. HHO20's self-contained base-code weight reduction, followed by distance balancing, yields a family of binary CSS quantum LDPC codes with $K=\Omega(N^{3/5}/\mathrm{polylog}(N))$ and $D=\Omega(N^{3/5}/\mathrm{polylog}(N))$. At each stage, $N$ denotes the blocklength of the resulting family.

  21. Quantum LDPCTheorem
    LTZ15 quantum-expander construction and distance

    Let $G=(A\cup B,E)$ be a biregular bipartite graph whose vertex parts $A$ and $B$ are nonempty, with $|A|=n_A$, $|B|=n_B$, strictly positive left degree $\Delta_A$, strictly positive right degree $\Delta_B$, and $n_B\leq n_A$, hence $\Delta_A\leq\Delta_B$. Let $H$ be its binary $n_B\times n_A$ incidence matrix, constructed from $G$, and let $C_G$ be the binary classical code with parity-check matrix $H$. The Leverrier--Tillich--Zemor diagonal hypergraph-product construction sets $H_X=(I_{n_A}\otimes H,H^T\otimes I_{n_B})$ and $H_Z=(H\otimes I_{n_A},I_{n_B}\otimes H^T)$. The rows of $H_X$ are orthogonal to the rows of $H_Z$, so they define the CSS code $Q_G$; each check row has weight $\Delta_A+\Delta_B$. This code has $N=n_A^2+n_B^2$, $K\geq(n_A-n_B)^2$, and $D=\min(d,d^T)$, where $d$ is the least cardinality of a nonempty set of columns of $H$ summing to zero over $\mathbb{F}_2$, and $d^T$ is defined analogously using a nonempty set of rows; either value is infinity when no such set exists. The graph is left-right expanding for $\gamma_A,\delta_A,\gamma_B,\delta_B>0$ when every $S\subseteq A$ with $|S|\leq\gamma_A n_A$ satisfies $|\Gamma(S)|\geq(1-\delta_A)\Delta_A|S|$, and every $S\subseteq B$ with $|S|\leq\gamma_B n_B$ satisfies $|\Gamma(S)|\geq(1-\delta_B)\Delta_B|S|$. If $\delta_A<1/2$ and $\delta_B<1/2$, then $D\geq\min(\gamma_A n_A,\gamma_B n_B)$.

  22. Quantum LDPCTheorem
    PK22 good qLDPC codes assuming the LPS spectral theorem

    Assume, as an external premise, the published LPS spectral theorem on the actual selected non-bipartite LPS Cayley graph family: its unnormalized complex adjacency operator restricted to zero-sum functions has norm at most twice the square root of one less than the graph degree. For every real $R$ with $0<R<1$ and every finite field $\mathbb{F}_q$, there is an explicit family of quantum LDPC codes over that field with unbounded physical block length. One family-independent bound controls both stabilizer-check weight and the number of checks incident to each physical qudit. For all sufficiently large block lengths $n$, the encoded dimension $k$ and distance $d$ satisfy $k\ge Rn$ and positive family-independent lower and upper bounds on $d/n$. One fixed finite Boolean program outputs all scalar-decorated sparse CSS checks of this same family in time bounded by a fixed polynomial in the physical output code length; decoding those outputs defines exactly the code carrier. The LPS spectral premise is retained explicitly and is not proved by this conditional coding theorem.

  23. Magic-state distillationTheorem
    Ngu24 binary CSS family with transversal CCZ

    Fix the source-permitted instantiation $m=8$, $F_{256}$, the trivial degree-three RMFE of width $s=1$, and the degree-three MFE of length $r=512$. There is an explicit sequence, indexed by $i$, of binary CSS codes $Q_i$ with AG lengths $n_i$, $K_{0,i}=\lfloor n_i/10\rfloor$, and parameters $[[N_i,K_i,D_i]]$ such that $N_i=512(n_i-K_{0,i})$, $K_i=K_{0,i}$, and $D_i\geq n_i/5-K_{0,i}$. The lengths tend to infinity and eventually satisfy $N_i/10240\leq K_i\leq N_i$ and $N_i/5120\leq D_i\leq N_i$. On three separately tagged encoded blocks, there is a set $T_i$ of physical triples obtained from the two MFE coordinate permutations, with one qubit from each block and with distinct triples sharing no physical qubit. Its size satisfies $|T_i|\geq\delta N_i$ for $\delta=1/512$, where $N_i$ is the length of one block. The product of $\operatorname{CCZ}$ over $T_i$ intertwines exactly through the three-block encoding with parallel logical $\operatorname{CCZ}$ on all $K_i$ logical coordinates, for every logical state.

  24. Magic-state distillationBound
    KT19 prime-qudit distillation with a vanishing exponent

    Let $p\ge5$ be prime. The qudit Hilbert space is $H_p=\mathbb{C}^p$, and the relevant diagonal third-level gate is $U_{1,3}$. Let $V$ satisfy the strong cubic condition $V*V\subseteq V^\perp$. For natural parameters $l,k$ satisfying $1\le k$, $l\le p$, $3l\le p+1$, $k\le l$, and $2\le l-k$, the Reed--Solomon construction has length $n=p-k$, logical dimension $k$, and proved source-used distance guarantee $d\ge l-k$, with physical $U_{1,3}^{\otimes(p-k)}$ implementing the inverse logical $U_{1,3}^{-1}$ action on the $k$ logical qudits. Its exponent is $\gamma_{p,l,k}=\log((p-k)/k)/\log(l-k)$. For each fixed admissible $p,l,k$, there is a depth-indexed $p$-dependent resource state $M_p$ and actual qudit distillation protocol whose reached error tends to zero as depth grows, equivalently attaining every sufficiently small positive target $\epsilon$, and whose successful-output cost is success-adjusted with exponent $\gamma_{p,l,k}$. Separately, as $p$ varies along a changing-prime sequence, the exponents obey $\gamma_{p,l,k}=O(1/\log p)\to0$; this is not a fixed-alphabet or fixed-resource statement.

  25. Magic-state distillationTheorem
    BK05 magic-state fidelity thresholds imply universality

    Let $\rho$ be a one-qubit density operator. Define $F_T(\rho)$ and $F_H(\rho)$ as the maximum square-root fidelities over the one-qubit Clifford orbits of the BK05 T-type and H-type magic states, respectively. If $F_T(\rho)>\sqrt{(1+\sqrt{3/7})/2}$, adaptive computation using ideal Clifford operations and copies of $\rho$ simulates universal quantum computation. For the H-type route, let $e_*$ be the unique fixed point in $(0,1/2)$ of the BK05 fifteen-qubit accepted-error recurrence and use the fidelity threshold $\sqrt{1-e_*}$; BK05 reports the corresponding threshold approximately as $0.927$. If $F_H(\rho)>\sqrt{1-e_*}$, the same universality conclusion holds.

  26. Locality tradeoffsBound
    BGKL restricted-connectivity tradeoff

    Let $I$ be a set of valid block lengths. For every $i\in I$, let $Q_i$ be a finite binary stabilizer $[[n_i,k_i,d_i]]$ code with $1\le d_i\le n_i$, and let $S_i$ be a fixed independent Pauli-generator presentation. Let $G_i$ be the support-interaction graph induced by $S_i$. For a graph $G$, let $s_G^{2/3}(r)$ be the maximum, over vertex subsets $W$ of cardinality at most $r$, of the minimum cardinality of a set $T\subseteq W$ such that $W=U_1\sqcup T\sqcup U_2$, $|U_1|,|U_2|\le2|W|/3$, and no edge joins $U_1$ to $U_2$. Fix real constants $\beta\ge1$ and $0<c\le1$. If $s_{G_i}^{2/3}(r)\le\beta r^c$ for every $i\in I$ and every integer $1\le r\le n_i$, then there is a real constant $\alpha=\alpha(\beta,c)>0$, independent of $i$, such that $k_i d_i^{(1-c^2)/c}\le\alpha n_i$ for every $i\in I$.   27. Magic-state distillationTheorem
