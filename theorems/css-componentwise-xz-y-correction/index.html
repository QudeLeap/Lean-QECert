CSS componentwise X/Z/Y correction from classical codes

Theorem statement

Let $P:\mathbb{F}_2^\iota\to\mathbb{F}_2^{\kappa_P}$ and $Q:\mathbb{F}_2^\iota\to\mathbb{F}_2^{\kappa_Q}$ be binary parity-check maps with mutually orthogonal rows, and let $T_{P,Q}$ be the exact common-fixed CSS code generated by the P-row Z checks and Q-row X checks. Let $t_X,t_Z\in\mathbb{N}$. Assume P is injective on the Hamming ball of radius $t_X$ and Q is injective on the Hamming ball of radius $t_Z$. Let I be finite, let $E_i=(x_i,z_i)$ be binary Pauli representatives, let $K_i=a_iE_i$, and write $I_+$ for the set of indices $i$ for which $a_i$ is nonzero. Suppose every $i\in I_+$ satisfies $\operatorname{wt}(x_i)\le t_X$ and $\operatorname{wt}(z_i)\le t_Z$, and the finite Kraus family is complete, $\sum_i K_i^\dagger K_i=I$. Then there exists a CPTP recovery channel correcting $T_{P,Q}$ for this Kraus family. Moreover, if $y$ is nonzero, $\operatorname{wt}(y)\le t_X$, and $\operatorname{wt}(y)\le t_Z$, bounded-ball injectivity gives nonzero words $P y$ and $Q y$; the equal-X/Z Y-support syndrome is $(P y,Q y)$, so both syndrome components are nonzero. Thus a Y coordinate contributes once to each separate component bound. This conclusion uses neither a total-Pauli-weight radius nor a CSS distance formula.
