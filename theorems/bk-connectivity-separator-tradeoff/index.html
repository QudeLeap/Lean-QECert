BK connectivity-separator tradeoff

Theorem statement

Let $\mathcal I$ be a cofinal set of valid block lengths. For every $i\in\mathcal I$, let $Q_i$ be a finite binary stabilizer QLDPC $[[n_i,k_i,d_i]]$ code with $2\le d_i\le n_i$, let $S_i$ be one fixed independent Pauli-generator presentation, and let $G_i$ be its actual support-interaction graph. Let $s_i(r)$ be the maximum, over vertex subsets $W$ of $G_i$ with cardinality at most $r$, of the minimum cardinality of $T\subseteq W$ for which $W=U_1\sqcup T\sqcup U_2$, $|U_1|,|U_2|\le2|W|/3$, and no edge of $G_i$ joins $U_1$ to $U_2$. Define $c_{\max}(i)=\max_{d_i\le r\le n_i}\log_r s_i(r)$. First, if there are a real $\gamma>0$ and a valid-index threshold such that $\gamma\le(1-c_{\max}(i))\log n_i$ thereafter, then there are a real $K>0$ and a valid-index threshold such that $k_i\le K n_i d_i^{2(c_{\max}(i)-1)}(\log n_i)^2$ thereafter. Second, if there are a real $c_0$ with $0<c_0<1$ and a valid-index threshold such that $c_{\max}(i)\le c_0$ thereafter, then there are a real $K>0$ and a valid-index threshold such that $k_i\le K n_i d_i^{2(c_{\max}(i)-1)}$ thereafter; this is the log-free terminal. The logarithmic-gap condition is an explicit Lean-QEC repair: it is not claimed to follow from pointwise $c_{\max}(i)<1$ or to be an assumption stated by BK22. The source reference $r_0$ is undefined and unused, so this statement assigns it no meaning.
